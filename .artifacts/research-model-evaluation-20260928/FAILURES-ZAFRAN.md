## Comparison limitations and non-failures

- No database deadlock or disk-full interruption was observed in these six runs. Earlier Premier storage incidents are a separate experiment.
- Exa deep requests completed in the observed Zafran runs; Grok4.7's termination was upstream researcher-model capacity.
- Grok4.7's post-failure availability probe at 09:30:51 UTC returned the same capacity class. It did not restart research; its price is unavailable and not treated as zero. Initial preflight is already included once in the run total.
- Both GLM attempts preserve provider Exa dossiers; these are not completed platform-agent dossiers. Untouched-02 also has a completed **no-op** reconciliation bookkeeping record, with no paid model call or generated section.
- Researcher model costs, provider research costs, common Muse reconciliation and preflight costs remain separate in `zafran-runs.json`. Estimated and settled ledger rows are not double-counted. AI Ark credits are not dollars.
- Identical revision-24 resource pins and retained context hashes do not establish identical Python runtime: parallel code changes occurred before later runs. Setup commit/diff paths are retained.
- Import checks establish preservation of authored findings; they do not establish source completeness or truth. Bundling, entity contamination, false conflict labels, research-gap claims and compressed public wording remain content issues documented per run. Provider interruption is not a fair completed-quality test.
- Trace verification counts model/provider observation IDs. It is not proof that every filesystem callback was audited. No private chain-of-thought is exported in this comparison.
