## Matched arms

1. **Historical observation:** retained old output, with its actual original context/catalog and
   provider dates. This is a defect baseline, not a gold-standard answer key.
2. **Repaired leaf baseline:** existing extraction/display ownership, complete frozen evidence,
   corrected exact seller/product/ICP/persona context and neutral catalog definitions. No new
   evidence acquisition. Record every unavoidable input or model difference.
3. **Specialists:** governed parent plus claim and narrative specialists, the same corrected context,
   catalog, originals and comparable model settings. Apply the same evidence/visibility rules to
   both repaired arms. Keep provider mappings deterministic and identical.

Changes between (1) and (2) isolate context/evidence/catalog repair. Changes between (2) and (3)
measure the ownership and correction loop. If models differ, add a separate model-factor arm or
report the comparison as confounded; never attribute all improvement to Deep Agents.

## Review checklist

This checklist is derived from observed defects and is ready for founder review; it is not a new
founder-approved scoring rubric. Review the claim and displayed sentence against its exact support.

| Case | Useful finding to preserve | Incorrect assertion to exclude or qualify |
| --- | --- | --- |
| Premier seller context | MagicDocs, intake and the selected clinical capabilities | Generic ABM platform pitch attributed to Insight Health |
| Premier report coverage | Referral/Open Access workflows, ownership uncertainty, operational pressures and explicit gaps | Omission solely because the parent supplied selected excerpts |
| Premier catalog | Correct field meaning with evidence from that account | Klara/catalog wording becoming a retrieved quotation |
| Premier provenance | Valid provider headcount with its provider provenance | Context note presented as a homepage statement |
| Premier field meaning | Actual accreditation, clinical recognition, registrations, RCM and CRM kept distinct | Newsweek/NPI/board certification mapped to ASC accreditation; RCM/fax equated with CRM |
| Premier relationships | Real vendor, customer, owner and physician relationships | Account presented as its own customer; unrelated committee interpreted as ACE |
| Premier employment | Correct local employer, time and responsibility | Katy/Little Rock namesake promoted to verified champion; outreach while unresolved |
| Distributed remit | Remote hospital executive and multinational decision remit | Blanket location exclusion or location alone proving employment |
| Probook current values | Dated provider count and newer corroborating evidence, with uncertainty | Prose acknowledges a contradiction but scalar readers still expose the rejected claim |
| Zafran commercial evidence | Funding, product/customer evidence and current ABM activity | More rows treated as stronger coverage; cached provider facts duplicated |
| Person field meaning | Public career, first-person interests, precise degree/year detail where sourced | LinkedIn post filed as X profile; workplace ritual called a private hobby; generic certificate called unique insight |
| Media | Exact transcript version, speaker evidence, qualifications, original timing | Unverified speaker promoted to personal quote; invented zero timestamp; report excerpt treated as primary speech |
| Hiring | Observed/closing dates, open/closed/historical/unknown states | Expired but reachable listing presented as current urgency |
| Corrections | Effective withdrawal, reclassification and dependency refresh with history intact | Prose correction markers that leave ordinary facts unchanged |
| Display | Cited facts, labelled interpretation, non-sensitive gaps and safe independent refresh | Missing employment hidden only in internal notes while outreach still assumes it |

For each item record: source reference/locator; expected entity/field/time/relationship; each arm's
claim IDs and displayed output; supported retained, missed, incorrect, qualified, or unavailable;
review rationale; and whether the observation is directly comparable across dates.

Report **missed useful findings and false assertions separately**. Also report unresolved findings
visible to the user, actual corrections applied, successful identity/remit resolution, and supported
seller arguments. Claim counts and contiguous-quote matches are diagnostics, not accuracy scores.
An absent source cannot count as a successful negative finding. Sensitive/inappropriate findings
are evaluated separately from accuracy and must not be made outreach-safe to improve recall.
