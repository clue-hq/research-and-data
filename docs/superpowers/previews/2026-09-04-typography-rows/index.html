What you are looking at

The ad text inspector's Typography section, drawn from the real panel's own markup, classes and design tokens — the five shipped rows (Text, Color, Font, Size / Weight, Alignment) at the top, then the rows item G proposes. The panel column is 480px, the width the shell gives the inspector.

No control on this page exists in the product, and Plan 4 does not build one. The gate is: are these the right rows, are these the right icons, and is lucide the right place to take an icon the local set does not have? Icon-by-icon provenance is in ICONS.md beside this file.

Row by row

Line height is a multiplier of the font size, so 1.04 is the Apollo headline's own value. The 0.05 stepper is the one piece of chrome on this page that is not lifted from the panel — no shipped field has a spinner. It is drawn from the panel's own select-chevron glyph so it speaks the existing language, but it needs its own yes/no.

Max lines and Wrap sit two-up in the panel's existing fieldGrid, like Size / Weight. The Wrap toggle is the shipped SegmentedControl — the web inspector's own Wrap row is exactly this control with Yes / No labels — so no new vocabulary is introduced, only the words On / Off.

Resize makes the same statement the Layout section's already-shipped "Fit to text" button makes in one click. Whether both belong on the panel is a real question, and it is part of this gate.

One inherited wrinkle

The shipped icon files hardcode their own stroke colour, and the set is not consistent — move-vertical and align-middle are #5E636C (the label colour), while move-horizontal and scan are #1C2028. So the Letter spacing and Resize glyphs sit darker than their labels. That is the product's state today, not a preview artefact.
