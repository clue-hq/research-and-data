# Account discovery-first experiment

Founder requested one account trial using complementary ordinary Exa searches before the deep
assignment, analogous to the person experiment. Active catalog and production runtime unchanged.

The account Deep Agent chooses searches, reviews sources, writes a pre-deep note, composes the
existing eleven-area assignment and investigates useful follow-ups. No fixed search quota or
completion/verification gate. Ordinary searches retain existing `type=auto` and 1,500-character
text settings. Deep requests retain the existing account builder, system and settings. Source
overviews reuse the person trial helper; full returned fields are retained. Provider operations
remain serialized by the existing account harness; batched context reads remain available.

Preparation copies only hash-verified original seller/project documents and the approved Head
brief from the corrected prompt preview. No earlier target reports, PoC answers or person results
are inputs. The Head brief is reused, not regenerated, to keep assignment context stable. Retained
personas are sparse and the documents are historical. Current account prompt/skill are copied
into the isolated package; only their preparation guidance is replaced. Source-review navigation
is exposed explicitly. Original prompts, runner snapshots and exact inputs are retained.

Prepare with `scripts/trial_account_discovery.py --context <snapshot> --output <fresh-directory>`.
Run with `scripts/preview_live_account_research.py --prepared <directory> --discovery-trial`.
Preparation makes no external calls; run uses configured account model/OpenRouter, Langfuse,
Exa, optional typed AI Ark company enrichment and public ATS reads. No fleet, database writes,
person jobs, claims or page synthesis. Native media transcription is not installed in this
account harness; search/page-based media investigation remains available.

Inspect actual search angles, acquired evidence, pre-deep note, exact Exa request, source reads,
follow-up decisions, findings and paid/model latency. Compare against retained PoC/Playground
results outside inputs. One live outcome is not a controlled causal A/B or a reliability estimate.
