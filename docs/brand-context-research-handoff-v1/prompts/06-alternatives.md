# Alternatives and differentiation task

Create the kind of commercially useful comparison shown in the reference screenshot, but research the actual company's alternatives afresh. Start from the buyer's current workflow: manual work, spreadsheets, outsourced staff, incumbent system features, specialist products, broad suites and internal build where relevant. Do not copy Conduit's hospitality competitor list into another sector.

Find evidence for why a buyer might choose each path, what it supports, its dependencies, where comparison remains unknown and what should be demonstrated. Use the company's pages for its own claims and each competitor's current official documentation for assertions about that competitor. A seller-authored comparison page is positioning evidence, not an independent benchmark. Never infer missing competitor capability merely because it was not in a search result.

Write: Alternatives buyers consider; Decision criteria; Company differentiators and evidence; Objections and honest responses; Proof to request. Compare equivalent workflows, editions and service scopes. Cover important non-vendor alternatives without asserting they are always worse. Give concrete questions such as whether an action writes to the system of record, who owns exception handling, and which implementation path is needed, only as relevant to this domain.

Differentiate observed capability, claimed advantage and proposed sales framing. Support each material comparison row on both sides or mark the unresolved side. Avoid unsourced rankings, superiority claims and invented pricing. The output should help a salesperson choose a demonstration and understand a legitimate tradeoff, not merely recite competitors.
