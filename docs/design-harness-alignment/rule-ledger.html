How this was built

  • The system prompt and the 21 tool descriptions were captured by building the real solo agent offline (scripted model, fake engine) and recording the first model call: 68,335 characters of system prompt, 21,529 characters of tool descriptions.
  • Every file the agent can open (operating note, 32 skills, 7 scene guides, 15 engine guides) and every per-turn wrapper and data file was read in full and split into rules. Conditional blocks the capture did not trigger were taken from source code.
  • A completeness check matched every sentence containing must / never / do not / cannot / only when / requires against the ledger; the 53 sentences only paraphrased are in “Audit additions”.
  • Working files: docs/design-harness-alignment/ (PROGRESS.md checklist, ledger/*.jsonl, issues.py, sources/).
