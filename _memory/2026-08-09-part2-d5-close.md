## What D5 is (and is not)

- Design turns + ingestion are **leased fleet work** (`FleetTaskKind.DESIGN_JOB`, one mechanical
  kind, envelope-discriminated). Created-and-offered in one transaction, born `queued`.
- Executed by `DesignJobWorkHandler` (`lumen_api/fleet_handler.py` — the ONE handler), composed
  two ways: `fleet_main` behind `design_runtime_enabled` (default off), and the design API's
  **embedded lifespan worker** (`LUMEN_EMBEDDED_FLEET_WORKER`, default on) so dev/tests drain
  through the same path. Daemon threads and the startup orphan sweep are gone.
- Sync turn body under `asyncio.to_thread`; supervised heartbeat unblocked; **generation-fenced
  terminal writes** (`DesignRunFencedError` / `DesignJobFencedError`) — the kill-and-resume test
  observes the zombie's refused write, the takeover's result surviving, exactly one terminal
  event.
- Checkpointer: sync `PostgresSaver` (same durable tables as `AsyncPostgresSaver`), thread id =
  run id. **Resume-as-restart**, honestly: `LumenDesignTools` mints its trace dir per attempt and
  `final.json` is the outcome authority — none of it in the checkpoint — so takeover clears the
  thread and re-executes the same frozen envelope. True resume = make the tools reconstructible
  from a run id (recorded residual).
- Stranded-work reaper (`lumen_api/fleet_reaper.py`): `running` + no live lease + terminal/absent
  task → re-offer ONCE (lease cleared, durable `reoffer_count`++, task re-enqueued
  `reopen_terminal=True`) → second sighting terminalizes `failed` with `design.stranded`.
  Live lease always wins. In-handler exception containment terminalizes before the task reports.
- Packaging: `py_lumen_obs`/`py_lumen_config` moved to `subsystems/clue-design/packages/*` as
  real uv members (hatchling refuses escaping paths — the move was forced); `apps/agent_runtime`
  is a uv member pinning `deepagents==0.6.12` (zero lockfile version changes — the one-version
  treaty was a packaging action). `import lumen_agent.harness` works with no path shims.
- The O5 bridge **survives D5** (ruling corrected in code + contract): worker path async-native,
  request paths synchronous by design; retirement owned by Part IV / Step-2.
- Editor: `queued` accepted as alive on the SSE-recovery path (was a hard "Lost connection"
  error); one new `it.each` case pins it.
