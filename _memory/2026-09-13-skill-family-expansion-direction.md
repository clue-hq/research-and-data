# Skill family expansion direction

- The founder explicitly requested remembering and expanding the design skill
  family beyond the initial four playbooks. Four is the first validation stage;
  the roadmap is roughly 15–20 useful, brand-independent creative families,
  not a hard ceiling or a fixed template menu.
- Keep the six shared responsibilities and grow playbooks/resources through
  demonstrated coverage gaps. Brand-specific imagery, effects and source
  observations stay scoped brand data; new shapes/layouts may be variants;
  missing capabilities require tools or components.
- Added a concrete candidate backlog and promotion process to
  `subsystems/clue-design/docs/design-agent-v1-skill-family-plan.md`, under
  "Expansion policy: four is the starting point". Candidate lifecycle and
  catalog filtering are proposed, not implemented runtime capabilities.
- Future additions need normal short-request comparison, multiple product
  brands including a held-out brand, missing-evidence behavior, first-pass
  visual review, native editability and 3–4 minute finished-creative measurement.
  Preserve failures; regress existing families; merge redundant candidates.
- Use metadata discovery and load relevant instructions/resources on demand.
  Do not inject every playbook into every run or auto-promote scraped patterns
  into global skills. No new creative runs or runtime changes in this update.
- Saved and read-back verified the explicitly requested global extension note
  `20260913T081205Z-design-skill-family-expansion.md`; existing global registry
  files were not changed. Checked document links, candidate-wave arithmetic
  and whitespace. This update changes planning and memory only.
