## Goal (one paragraph)
Add the **budget-admission gate** to the per-contact fan-out — the concrete cost dial (Doc C §5,
*fan-out-per-account × accounts-per-pass*). Before each `profile_contact`, ask `BudgetEngine.check(scope=
ACCOUNT)`; an `ACCOUNT`-scope **DENY** stops admitting more contacts for that account → a **partial
committee with coverage metadata, not a failure** (coverage-confidence, not completeness). A **RUN**-scope
**GRACEFUL_STOP** must bubble up so the handler (M8A.2) can return `PhaseResult(PAUSED)`. The four bounds
all live at this one chokepoint.

## The exact insertion point
`_profile_contacts` (orchestrator.py ~lines 320-354) currently fans out with one `asyncio.gather` over
ALL admitted members:
```python
async def _one(contact_id):
    async with semaphore, self._session_factory() as conn:
        return await self._profile_contact(conn, contact_entity_id=contact_id, ...)
return tuple(await asyncio.gather(*(_one(cid) for cid in contact_ids)))
```
`gather(all)` cannot express "DENY stops admitting the rest." Restructure to an **admit-then-launch loop**:
check budget per contact sequentially; ALLOW → schedule the profile under the semaphore; DENY/GRACEFUL_STOP
→ stop admitting and break. Recommended shape:
```python
async def _profile_contacts(self, contact_ids, *, campaign_run_id, account_entity_id, run_id, tenant_id, tier):
    semaphore = asyncio.Semaphore(self._config.max_contacts_in_flight)
    facet_budget = ...  # unchanged
    tasks: list[asyncio.Task[ContactProfileResult]] = []
    stop: BudgetVerdict | None = None
    for contact_id in contact_ids:
        decision = await self._budget.check(
            scope=BudgetScope.ACCOUNT,
            projected_cents=self._config.per_contact_estimate_cents,
            campaign_run_id=campaign_run_id,
            entity_id=account_entity_id,
            account_run_id=run_id,
        )
        if decision.verdict is BudgetVerdict.ALLOW:
            tasks.append(asyncio.create_task(self._profile_one(contact_id, semaphore, facet_budget, ...)))
        else:  # DENY (partial) or GRACEFUL_STOP (pause)
            stop = decision.verdict
            break
    results = tuple(await asyncio.gather(*tasks))
    return results, stop
```
- Thread `campaign_run_id` into `_profile_contacts` (it lives in `run_one`; pass it through — it is not
  currently passed).
- `BudgetScope`, `BudgetVerdict`, `BudgetEngine` are in `clue_research.core` (frozen). `BudgetVerdict ∈
  {ALLOW, DENY, GRACEFUL_STOP}`. `check(...) -> BudgetDecision{verdict, scope, projected_cents, cap_cents}`.
