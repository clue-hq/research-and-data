## The shape (rulings R-D4-1..8, frozen at planning)

- **Custody:** platform storage (fs/S3 behind `StorageBackend`) durably owns every design byte;
  `clue_design.storage` is the one seam (row-before-blob `record_artifact`, fail-closed digest
  reads); `DesignBlobStore` is the sync handle on the O5 bridge (dies at D5).
- **Keys:** `{workspace_id}/design/{sha256}` — the `design` segment keeps design keys disjoint
  from claim-evidence keys so the claim-refcount DSAR erasure can never purge design-cited
  bytes. Required widening the B2 `artifact_key_encodes_scope` CHECK (migration `13cd5078d697`,
  which also adds the `artifact_content_sha256` index for the digest-first public read).
- **Engine cache:** the Rust helper still reads/writes local paths (engine untouched, per the
  master plan), so `{cache_root}/{ws}/sha256/{ab}/{digest}` survives as a transient
  materialization cache — write-back after every engine write (ingestion chokepoint
  `_RecordingCore`; scene-persist backstop at the accept seam), read-through before every
  engine read. Wiping it loses nothing (proven by the cache-wipe rehydration test).
- **Locations:** `record_json.media.location` → `{"provider": "clue-storage", "opaque_ref":
  <storage key>, "url": null}`; readers dual-accept `local-store`/`opaque_asset_store` and
  always resolve by digest, never by parsing a ref as a path.
- **Serving:** `/asset-store/{digest}` stays public (D2.5A CORS ruling) and resolves live
  design-namespace rows across tenants (R-D4-7) — Part-IV custody residual stands.
- **Exempt:** `.generation-cache.json` (mutable JSON, per-ws file in the cache root; Postgres
  home is D5's).

## Residuals carried forward (sites documented in code + round notes)

- Font custody is single-workspace (`library_workspace_id()` = dev workspace env) — Part IV.
- `api_blob_store()` reads settings, not `app.state.storage` (off-request defaults only) — dies
  with the D2.5A workspace residual at D5.
- `design_engine_artifact` blobs (derive/export outputs) are registered but never GC'd — needs
  a retention rule, not a refcount.
- `delete_design_bytes` deletes the blob inside the caller's transaction (O5: one tx per call);

  the bridge dies at D5.

  follow-up; Part-IV auth owns.
- Non-`CONCURRENTLY` index build in `13cd5078d697` — fine for a never-shipped revision; convert
  if this ever applies to a populated production `artifact` table.
