## Key decisions
- **pydantic v2 models, frozen + extra="forbid"** everywhere. `frozen=True` = append-only
  (no in-place mutation; supersede via `superseded_by`). User asked earlier for pydantic;
  this is where the runtime validation lives (mypy = static, pydantic = runtime — both kept).
- **Module split** under core/: `primitives.py` (NewType ids EntityId/ClaimId/RunId + factories;
  constrained scalars SourceTier 1..4, Confidence 0..1, Corroborations, CostCents, UnitInterval;
  UtcDatetime=AwareDatetime), `enums.py` (all §3 StrEnums), `field.py` (FieldKey open registry +
  FieldClass + namespace helpers + FieldDef), `entity.py` (Entity, AccountEntity + as_entity()),
  `claim.py` (Claim, DiscoveryProvenance, can_be_promoted), `source.py` (SourceManifest),
  `resolver.py` (Resolver Protocol), `handoff.py` (CurrentValue/ICPSpec/AccountHandoff + submodels),
  `factories.py` (account_claim/contact_claim, value_json (de)ser, tier-order helpers), `__init__.py`
  (63-name public seam via __all__). Intra-core imports are fine (import-linter only forbids
  core→OTHER packages).
- **EntityId = NewType("EntityId", UUID)** — distinct static type; pydantic validates as UUID at
  model-construction so a free-text name is rejected (encodes "keys on a resolved id, never a name").
- **Claim construction invariants** (model_validator, all raise pydantic.ValidationError):
  contact ⟹ identity_binding+use_class REQUIRED; account ⟹ both must be None (forbidden);
  tier-4 ⟺ extraction_method==llm_synthesis (biconditional); source_url required for
  {api,scrape,llm_synthesis}. Field constraints: source_tier∈1..4, confidence∈0..1.
  NOTE: tier-4 with no evidence_span IS constructible (exists as UNVERIFIED) — the span rule is a
  PROMOTION rule, not construction.
- **can_be_promoted(claim)**: False if (tier4 & no span) OR (contact & WEAK binding); else True.
  Pure predicate, callable by M9. verification_status enum field added (additive; default UNVERIFIED).
- **FieldKey**: open registry, not enum. `Annotated[str, AfterValidator]` validates well-formedness
  (lowercase dotted, ≥2 segments). classify_field_key longest-prefix → FieldClass {CORE, ACCOUNT,
  ACCOUNT_RESONANCE, CONTACT, CONTACT_FACET, PACK}. register_pack() for M3.3; packs stay open.
- **Resolver Protocol** `@runtime_checkable` (tier:int; resolve(entity,field)->list[Claim]). Static
  conformance proven in resolver.py under `if TYPE_CHECKING:` — positive assignment + a negative
  `# type: ignore[assignment]` that self-guards via mypy strict `warn_unused_ignores`.
