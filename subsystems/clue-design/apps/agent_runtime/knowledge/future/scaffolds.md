# Future Capability Scaffolds

Status: future scaffold.

These categories are intentionally documented before they are fully supported
so agents know the map of the product without assuming the capabilities exist.

- DSL edit directives: `before`, `after`, `clone`, `replace`, `undo`, `redo`.
- Slot runtime: repeaters, conditionals, fit fixtures, binding sets.
- Typography: line-height, letter-spacing, rich text, RTL/bidi, font
  subsetting.
- Layout: grid systems, pagination, responsive variants, advanced alignment.
- Design systems: generated brand kits, semantic aliases, mode-aware tokens.
- Assets: upload, processing, provider generation, vectorization, resolver.
- Export: print-grade PDF, browser screenshots, bleed/safe-area proofing.
- Editor: complete asset picker, direct manipulation, inspected repairs.

When a task requires one of these, record a gap instead of simulating the
feature in prompts or Python-side mutation.
