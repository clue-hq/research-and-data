# Logo And Brand Assets

Brand assets are not interchangeable image IDs. Use their semantic asset
tokens and usage rules.

## Asset Roles

Common Brand Kit asset roles:

- `logo.primary`
- `logo.reversed`
- `logo.mark`
- `logo.wordmark`
- `asset.illustration.primary`
- `asset.texture.subtle`
- `asset.icon.primary`

Logos may specify:

- usage
- color mode
- preferred dimensions
- minimum size
- clearspace
- allowed backgrounds
- license/provenance

Illustrations and textures may specify:

- style tags
- allowed contexts
- preferred color tokens
- recolor/crop policy
- license/provenance

## Authoring Rules

Place logos on approved surfaces. If a Brand Kit says a logo is allowed only on
`surface.brand`, do not place it on `surface.page` or `surface.card`.

Use asset tokens or known asset IDs from the Brand Kit. Do not invent
production asset IDs.

When the task needs imagery and no approved asset exists, ask the coordinator
to use the asset tool or record an `assets` gap. Do not fake production
imagery with unrelated decorative shapes.
