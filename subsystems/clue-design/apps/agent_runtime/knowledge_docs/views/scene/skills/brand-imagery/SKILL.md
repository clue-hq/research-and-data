# brand imagery

Start with the request's imagery requirement; `knowledge/scene/references.md`
says how a request for new imagery is fulfilled.

When imagery is optional, choose whether a suitable real image, a generated
component or typography alone best carries the message. A type-led concept can
still use a generated background. Preserve the inspected reference's material,
blur, tonal depth and texture when those qualities define the chosen direction;
palette similarity alone is insufficient.

`knowledge/scene/components.md`, already in your prompt, covers native
text/geometry and independent authentic logo/product layers. Keep those editable and inspect the finished
composition as well as every generated component.
