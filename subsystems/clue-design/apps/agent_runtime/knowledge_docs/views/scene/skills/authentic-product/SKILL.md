# Authentic product

Inspect the real product image first. Choose the product feature or recognizable
object that carries the message; crop only when the relevant content survives.
Write copy grounded in what the product/source context supports, not invented UI
labels or outcomes. Keep product pixels independent of background, logo and text.

Use `authentic_image` with the supplied asset ID and the `product` source role.
Never generate a substitute dashboard, alter factual UI, or label a generic card
as product evidence. If no useful authentic image exists, choose another playbook
and record the gap unless the request explicitly requires that image.

Read `knowledge/scene/components.md`; if a generated setting helps, also read
`/.deepagent/skills/generative-imagery/SKILL.md` (product scene). Generate only the setting/treatment, with honest
conditioning roles. Product references are not automatically style references.

Review crop, screen legibility, native copy and authentic branding separately.
A large screenshot can still fail if its useful detail is too small at placement
size. Change composition or crop instead of decorating an illegible rectangle.
