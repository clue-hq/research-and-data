# Brand and tokens

Read the real brand card and its available role tokens. Use its color, spacing
and typography roles instead of guessed values. A token example is not evidence
that the token exists in this kit. New branded text binds `style($type.<role>)`;
do not invent weights, font files or token names. Record missing roles honestly.

`knowledge/design-systems/token-taxonomy.md`, `brand-kits.md`, `modes.md` and
`brand-validation.md` own token mechanics and diagnostics. The actual card owns
identity. `knowledge/scene/components.md` owns authentic independent logo/image
placement; `knowledge/scene/review.md` owns visible brand fit. Token-valid colors
still need enough contrast in the actual composition.
