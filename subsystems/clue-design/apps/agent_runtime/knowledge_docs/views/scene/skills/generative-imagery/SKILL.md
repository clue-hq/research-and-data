# generative imagery

Read `knowledge/scene/references.md` for the supported generation call and reference custody, and `knowledge/scene/components.md` for page-first staging and independent native layers. Generate the component only; do not flatten a finished ad or regenerate exact product/logo pixels.

For an exact crop of authentic source pixels, follow the `crop_image` bounds and
inspection workflow in `knowledge/scene/components.md`; generation is unnecessary.
